# Architecture Diagrams

This directory should contain:
- `system-architecture.png` - High-level system architecture diagram
- `database-erd.png` - Entity Relationship Diagram

For evaluation purposes, these images can be created using:
- Draw.io (diagrams.net)
- Lucidchart
- Excalidraw
- Or any diagramming tool

The architecture is described in text format in `docs/architecture.md`.
